# ai-guardrails

CLI for standardizing AI development guardrails, skills, tools, and CI/CD templates.

## First commands

```bash
brew tap gautampachnanda101/tap
brew install ai-guardrails
ai-guardrails --help
```

## Installation

```bash
brew tap gautampachnanda101/tap
brew install ai-guardrails
```

Upgrade and verify:

```bash
brew upgrade ai-guardrails
ai-guardrails --help
```

Use `ai-guardrails <command> --help` to inspect the commands available in the installed version.

## Help

Use `ai-guardrails --help` for the installed command set. Report tap packaging issues through the [public issue tracker](https://github.com/gautampachnanda101/homebrew-tap/issues).
